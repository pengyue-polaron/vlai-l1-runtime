# 从关节扭矩估计末端力的研究路线与文献定位

更新日期：2026-10-12。状态：研究方案，尚未验证创新性或完成论文实验。

目标是让机械臂利用自身关节位置、速度和电机反馈，估计末端六维力与力矩；通过仿真初始化、真实物理实验和自主实验选择，减少在新机械臂上的适配成本。最终产物是运行时持续输出力估计的系统，而不局限于一组离线标定参数。

初步判断：方向有实际价值，可以将 RA-L 作为研究目标，但整个领域并非蓝海。“仿真预训练＋真机砝码实验＋神经网络＋跨机械臂”以及“主动优化采集轨迹”都有先例。候选贡献应落在实验如何选择、为何改善力估计、跨平台需要多少数据与人工介入，以及独立验证的精度。

本文是针对选题的文献梳理，不是穷尽式系统综述。下文将已有结果与待验证假设分开；没有发现完整对标，不代表可以宣称首创。运行状态和硬件约束以 [HANDOFF.md](HANDOFF.md) 与 [SAFETY.md](SAFETY.md) 为准，估计链路的实现说明见 [FORCE_ESTIMATION.md](FORCE_ESTIMATION.md)。研究方案不扩大当前硬件操作权限。

## 问题定义

首先固定坐标系、末端参考点、正负号及输出含义。六维 wrench 记为 `w = [Fx, Fy, Fz, Mx, My, Mz]`，力的单位为 N，力矩为 N·m。至少区分：

- **末端总外加载荷**：包括抓取物体的重力作用。
- **额外环境接触力**：先补偿工具及抓取物体的动力学，再估计环境接触。

二者不能混用训练标签。抓住已知砝码可以提供前一种监督，但若将其重量纳入载荷补偿，后一种输出在无接触时应接近零。

采用环境作用于机器人的符号约定时，基本关系为：

```text
M(q) qdd + C(q, qd) qd + g(q) + friction = tau_motor + tau_external
tau_external = J(q)^T w
```

运动学负责几何、坐标转换与可观测性；动力学和执行器模型负责分离自身运动、重力、摩擦及外力。电机协议中的反馈扭矩不等同于经过物理标定的关节输出扭矩，也不等同于外力矩。学习模型可以替代部分计算或补偿误差，但不能消除缺乏观测信息造成的歧义。

## 传统方法与主动辨识的近邻工作

| --- | --- | --- |
| Swevers 等，1997，Optimal Robot Excitation and Identification | 用有限傅里叶级数参数化激励轨迹，优化参数估计不确定性，结合最大似然辨识。[作者机构版](https://lirias.kuleuven.be/bitstream/123456789/166506/1/robot_identification.pdf) | 仅提出自动计算激励轨迹。 |
| Haddadin、De Luca、Albu-Schäffer，T-RO 2017，Robot Collisions | 系统讨论仅依靠本体传感器的模型式碰撞检测、隔离与辨识。[作者版](https://iris.uniroma1.it/retrieve/e383532a-2aa9-15e8-e053-a505fe0a3de9/Haddadin_Postprint_Robot-Collisions_2017.pdf) | 将检测到接触等同于准确估计末端六维力。 |
| Wahrburg 等，T-ASE 2018，Motor-Current-Based Estimation of Cartesian Contact Forces and Torques | 结合电流、角度、速度、动力学和卡尔曼滤波估计末端 wrench，包含自动滤波标定及柔顺控制应用。[论文](https://ieeexplore.ieee.org/document/7914641) | 仅实现电机信号到末端力的基础链路。 |
| Lu、Shen、Zhuang，2023，External force estimation for industrial robots using configuration optimization | 将半参数摩擦补偿与基于雅可比条件数的构型优化结合，改善外力估计。[期刊页面](https://hrcak.srce.hr/en/315756) | 仅选择雅可比条件更好的估力姿态。 |
| Wong、Suleiman，2023 预印本，2024 修订，Sensor Observability Analysis | 分析姿态变化下各任务空间方向的传感能力，用于优化与零空间控制。[论文](https://arxiv.org/abs/2305.06403) | 将运动灵活度、传感可观测性和参数可辨识性视为同一指标。 |
| Zhou、Schoellig，CDC 2019，Active Training Trajectory Generation for Inverse Dynamics Model Learning with Deep Neural Networks | 将网络不确定性、主动学习与样条轨迹优化结合，分轮选择信息量大的采集轨迹；展示仿真实验。[作者版](https://www.dynsyslab.org/wp-content/papercite-data/pdf/zhou-cdc19.pdf) | 仅让模型选择下一轮逆动力学训练数据。 |
| Daş、Burdick，2023，An Active Learning Based Robot Kinematic Calibration Framework Using Gaussian Processes | 使用 GP 建模运动学残差，并主动选择测量点以减少标定实验。[论文](https://arxiv.org/abs/2303.03658) | 将自主、数据高效的标定作为未经限定的新概念；该工作目标是运动学误差，不是六维力。 |

这些工作要求本项目区分两类目标：让参数或关节扭矩预测更准确，以及让指定工作区域的末端力估计更准确。二者相关，但误差经过姿态相关的雅可比映射后，对不同力方向的影响不同。对此建立更合适的实验选择目标，是候选研究问题，不能单凭概念宣称创新。

## 学习式力估计与迁移的近邻工作

| 工作 | 方法与实验范围 | 与本项目的关系 |
| --- | --- | --- |
| Liu、Wang、Wang，2021，Sensorless force estimation for industrial robots using disturbance observer and neural learning of friction approximation | 动力学辨识、神经网络摩擦补偿与扰动卡尔曼观测器结合。[论文](https://www.sciencedirect.com/science/article/pii/S0736584521000521) | 物理模型加学习残差已有先例。 |
| Osburg 等，Frontiers in Robotics and AI 2022，Using Deep Neural Networks to Improve Contact Wrench Estimation of Serial Robotic Manipulators in Static Tasks | 仿真训练、真实砝码数据训练、静态 wrench 估计及相近 KUKA 型号间迁移。[全文](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2022.892916/full) | 与“仿真＋砝码＋跨机械臂”的设想直接重合，应优先阅读。 |
| Shan、Pham，RA-L 2024，Fine Robotic Manipulation without Force/Torque Sensor | 从内部信号学习外力估计，展示插销和手动引导任务。[论文](https://arxiv.org/abs/2301.13413) | 估计器还需要通过实际操作体现用途。 |
| Shan、Pham，ICRA 2024，Sensorless Estimation of Contact Using Deep-Learning for Human-Robot Interaction | 使用保留运动历史的 Motion Discriminator 输入和残差网络处理摩擦滞回。[全文](https://arxiv.org/html/2309.16219v2) | 同角度、不同历史下的扭矩差异并非尚无人研究的问题。 |
| Shan、Pham，RA-L，Fast Payload Calibration for Sensorless Contact Estimation Using Model Pre-training，2024 预印本 | 多载荷预训练，短轨迹选择模型或提取载荷特征，快速调整补偿。[全文](https://arxiv.org/html/2409.03369v1) | 大范围离线学习与快速在线适配已有直接先例。 |
| Kim、Lim、Park，Transferable Collision Detection Learning for Collaborative Manipulator Using Versatile Modularized Neural Network | 模块化网络与迁移学习，目标机器人不需要碰撞数据；展示两个源机器人和一个目标机器人。[作者页面](https://daegyulim.github.io/tro2021) | 跨机器人迁移已有研究；碰撞分类不等价于连续六维力估计。 |
| Oh 等，FACTR 2，2026 预印本 | NEXT 学习自由运动扭矩并以残差估计外部关节扭矩，支持低成本机械臂力反馈与策略学习。[全文](https://arxiv.org/html/2606.12406v2) | 少量自由运动数据学习力感知，是本项目必须比较的强基线。 |

Osburg 等的实验使用带关节扭矩传感器的 KUKA，真实数据包含 33 万个随机姿态数据点，并向相近的 iiwa 14 型号测试迁移。它与依赖电机侧估计、传动和摩擦误差更显著的平台存在区别；但换成低成本硬件本身不能充分证明方法创新。[原文](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2022.892916/full)

Fast Payload Calibration 的核心并非真机 RL：离线采集 69 种质量与重心组合，每种 30 分钟；在线执行 4 秒往返，选择预训练模型或构造载荷特征。其目标是补偿手持物体的影响，以便估计随后发生的接触。四秒不是从零建立完整模型的时间。[原文](https://arxiv.org/html/2409.03369v1)

FACTR 2 的主要定量输出是外部关节扭矩。接触评价以 Franka 厂商外力矩估计作为参考；Piper 的定量评价使用无接触数据，接触效果另通过遥操作评价。因此其结果不能直接作为低成本机械臂绝对六维力精度的证明。比较时要保持输出量、真值来源和测试条件一致。[实验部分](https://arxiv.org/html/2606.12406v2#S6)

RL 与无传感器力感知的组合也已有研究。2026 年预印本分别探索了混合力估计辅助轮腿机器人操作策略，以及离线／在线 RL 的手术夹持力调节。这些任务与固定基座机械臂的六维估计不同，但“用了 RL”不是独立贡献。[轮腿操作](https://arxiv.org/abs/2609.13779)、[手术夹持](https://arxiv.org/abs/2602.23870)

## 候选研究问题

建议的核心假设是：

> 在电机反馈有限、摩擦具有历史依赖的机械臂上，依据末端力误差选择载荷与运动实验，可以降低跨平台力感知达到指定精度所需的真实采集时间和人工成本。

这个假设尚未被本项目验证。本轮文献梳理也不足以确认该限定问题的首创性，需要继续追踪近邻工作的引用与后续成果。

### 针对最终力误差选择实验

候选实验由物体、抓取位置、姿态、进入姿态的方向、轨迹和停留时间共同定义。选择目标同时考虑模型对摩擦及扭矩偏差的不确定性，以及姿态对末端各方向力误差的放大。

先比较可解释的优化或主动学习策略，再决定是否引入 RL。简单的雅可比条件数优化和“挑网络最不确定的点”应作为基线，而不是将其换一个实现后作为主要创新。

### 用受控物理实验分离载荷与内部误差

已称重、重心及固定关系明确的物体提供物理监督。空载与加载对照需要记录实际姿态及运动历史，避免将装卸接触、静摩擦变化和真实载荷混入同一个残差标签。研究重点是如何通过少量实验消除混淆，而不是仅增大网络。

静止且悬空时可以由质量、重力和力臂构造参考载荷；动态实验还需考虑惯性和加速度。仅依靠重力物体不能自动证明任意方向、任意力矩的六维精度。

### 在新机械臂上自主适配

迁移对象需要明确：模型参数、物理先验、残差表示或实验选择策略。相同型号的不同个体、不同型号的少量适配，以及每台分别重训，是不同级别的证据。

优先验证两个不同平台上的同一套适配流程，再考虑扩展到三个平台。将一个平台留作目标平台，固定源模型和算法后才开始目标平台适配；独立评价达到精度要求需要多少采集、计算和人工工作。

## 系统设计建议

| 模块 | 责任 | 需要检验的收益 |
| --- | --- | --- |
| 仿真和物理先验 | 提供初始几何、动力学结构与误差假设，生成候选实验 | 相比从头学习，是否降低真机采集成本；仿真偏差是否导致负迁移。 |
| 时序力估计器 | 根据关节反馈及历史估计外力矩或末端 wrench | 相比物理观测器与普通时序网络，是否改善独立测试误差。 |
| 实验选择器 | 在约束内选择载荷、姿态与轨迹 | 相同模型、时间和运动预算下，是否优于固定、随机和传统优化。 |
| 自主执行与数据质量检查 | 执行物体操作、采集、更新与异常退出，记录人工介入 | 实际减少多少人工工作；失败与恢复成本是多少。 |
| 独立评价 | 使用保留数据和参考测量验证输出 | 改善是否覆盖未知载荷、姿态、运动历史和目标机械臂。 |

估计器可以是物理模型、直接回归网络或物理与学习的组合。若有力标签，监督学习可直接优化预测误差；RL 更适合承担序贯实验决策。奖励不能仅依据训练误差或模型自报置信度，否则可能提高代理指标却没有改善真实力精度。

Agent 可以组织实验、训练和审计，但自主执行本身需要用人工介入次数、可重复性和失败成本评价。底层运动必须继续由受约束的独占控制进程执行。现有右 Follower 小幅诊断不等同于已实现自动抓取、全工作空间探索或任意 RL 控制。

运行中的主动探测与离线标定应分别评价：前者需要权衡对任务的扰动，而且探测动作可能改变接触力，不能默认动作前后的外力相同。

## 实验与评价方案

先固定输出范围与真值，再确定精度目标。若只验证静态或特定方向，论文应明确限定，不提前声称完整动态六维感知。

### 基线与消融

- 物理动力学补偿与动量／扰动观测器。
- 普通 MLP、LSTM 或已有运动历史模型；优先复现与硬件输入相容的近邻方法。
- 固定往返、随机可行轨迹、传统激励优化、基于不确定性的主动采样，以及拟议实验策略。
- 去掉仿真初始化、物理监督、历史输入或任务空间误差目标的消融。

隔离算法收益：比较采集策略时保持估计器、更新预算和可用监督一致；比较模型时保持训练数据一致。物理方法也需要合理辨识，不能用未经核对的 URDF 与充分训练的网络作不公平对比。

### 独立测试

- 按完整实验、日期、载荷或机械臂划分数据，避免相邻采样帧泄漏。
- 主动策略可以选择训练实验；最终测试集保持独立，不能由策略挑选容易通过的姿态。
- 砝码质量可用于产生训练标签，但最终估计器不能把待估物体的已知质量或身份作为隐藏答案。
- 六维力结论需要独立、可靠的参考；验证阶段可临时使用标定过的 FT 传感器，并与部署时的传感需求分开说明。
- 检查静止、反向、运动到静止、不同热状态和不同接近历史；另测未见物体、工具和姿态。
- 工具接触以外的连杆接触、多点接触和不可观测姿态应明确排除或单独研究，不默认都能映射成唯一末端力。

### 主要指标

分别报告三个力分量与三个力矩分量的 MAE、RMSE、偏差及较大误差分位数，不直接混合 N 与 N·m。同步报告无接触误报、估计延迟、有效覆盖率、拒绝输出比例以及不确定性与真实误差的对应关系。

核心曲线为独立测试误差随真实采集时间或实验次数的变化；同时统计物体切换、计算和人工介入成本。应覆盖重复试验和跨日期测试，并用一个实际接触任务检验估计的使用价值。

## 当前证据与推进顺序

截至 2026-10-11 的本地右 Follower 实验已能自动执行受限往返、保存原始反馈并验证失能。一次遥控器加载对比中，J2 反馈扭矩变化约 0.48 N·m，卸载后接近原值；加载时姿态同时变化，且该轮未完成最终空载往返。因此这只是载荷相关响应，不能视为已称重 300 g 的估计精度或六维力验证。

当前局部空载模型只覆盖很小的姿态范围。约 0.12 度的其他关节变化就超出其已验证范围，说明需要扩展数据与模型，而不是要求使用时完全不动。J4 的空载误差与 J2 的加载变化属于不同关节，不能相除后宣称信噪比。上述本地诊断数据尚不是公开论文数据集，证据位置与运行结果见 [HANDOFF.md](HANDOFF.md)。

建议依次完成：

1. 核对反馈扭矩的物理量纲、坐标、工具质量和参考真值，建立可重复的静态／低速评价。
2. 建立一个较强的物理或时序估计基线，确认误差来源及可达到的精度。
3. 在同一机械臂上，公平比较固定、随机、传统优化与主动采集。
4. 完成载荷操作和训练闭环，统计真实人工成本，而不是仅展示自动运行视频。
5. 在第二种机械臂上做受限数据适配及独立测试，决定是否扩展平台和动态范围。

若主动方法在公平预算下没有稳定收益，就调整或放弃该贡献；若只有关节残差准确而末端力不准，则继续检查几何、可观测性与扭矩尺度。是否使用 RL、是否扩大自主化范围，应由这些结果决定。

## 论文定位

暂定主题：**通过自主物理实验实现跨机械臂的高效末端力感知适配**。

有说服力的贡献应集中于一种具体实验选择方法、解释其适用条件的分析，以及跨平台且有独立真值的验证。RA-L 可以作为目标，但当前只有工程基础和待验证假设，尚无可承诺的论文级结果。下一轮文献审查应继续追踪上述主动辨识、载荷标定和低成本力估计工作的后续成果，并核对其代码、数据预算和传感器假设。
